Canadian Bank Trust
Interactive fintech/crypto website package.

Open index.html in a browser. Registration, account dashboard, wallet pages,
transfer workflow, verification workflow, support center and admin interface
work in the browser using local storage.

For real-money production operation, connect a secure backend, database,
authentication, KYC provider and appropriately regulated banking/crypto partners.
The interface does not create real bank accounts, custody real funds, or execute
real financial transactions.
